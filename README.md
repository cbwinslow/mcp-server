MCP Server Platform
===================

This repository contains a host‑native (no Docker required) platform for:

- Async FastAPI MCP API with Postgres + pgvector
- Neo4j + APOC for the knowledge graph
- Supabase Auth (GoTrue) for JWT‑based API protection
- LlamaIndex hybrid retrieval (pgvector + graph)
- Graphiti MCP (temporal graph memory) integration
- Crawl4AI MCP for web crawling
- CrewAI agents and tools for ingestion and KG management

Start with docs/README-quickstart.md for installation and usage.
