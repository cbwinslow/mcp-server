**High-Level Data Model (Postgres + pgvector)**

- `repositories`
  - id (uuid, pk), name (text, unique), url (text), default_branch (text), created_at (timestamptz)
- `files`
  - id (uuid, pk), repo_id (fk), path (text), language (text), sha (text), size (int), updated_at (timestamptz)
  - index: (repo_id, path), unique (repo_id, sha) partial by branch if needed
- `chunks`
  - id (uuid, pk), file_id (fk), chunk_index (int), text (text), tokens (int)
  - index: (file_id, chunk_index)
- `embeddings`
  - id (uuid, pk), chunk_id (fk), embedding (vector[dim]), model (text), created_at
  - index: ivfflat on `embedding` with `lists=100` (set per corpus size)
- `crawler_jobs`
  - id (uuid, pk), repo_id (fk), status (enum), started_at, finished_at, stats (jsonb)
  - index: status, started_at
- `tasks` (optional for CrewAI)
  - id, type, payload (jsonb), status, created_at, updated_at
- `entities` (optional tabular mirror for KG)
  - id, type, properties (jsonb), source_ref (text)
- `relationships` (optional mirror)
  - id, src_entity_id, dst_entity_id, type, properties (jsonb)

Notes:
- Choose `embedding_dim`: 1536 (OpenAI) or 1024/768 based on provider; store as config.
- Enable `pg_trgm` for fuzzy file/path search.
- Add RLS later via Supabase policies if multi-tenant.

**Graph Model (Neo4j)**

- Node Labels:
  - Repository {id, name, url}
  - File {id, path, language, sha}
  - Chunk {id, index, text_hash, tokens}
  - Symbol {name, kind, signature, file_path}
  - Topic {name}
  - Entity {type, properties} (generic domain)
- Relationships:
  - REPO_CONTAINS: (Repository) -[:CONTAINS]-> (File)
  - FILE_CONTAINS: (File) -[:CONTAINS]-> (Chunk|Symbol)
  - REFERENCES: (Symbol|File) -[:REFERENCES]-> (Symbol|File)
  - SIMILAR: (Chunk) -[:SIMILAR {score}]-> (Chunk) [optional]
  - ABOUT: (Chunk|Symbol) -[:ABOUT]-> (Topic)
  - MAPS_TO: (Entity) -[:MAPS_TO]-> (Symbol|File|Chunk)
- Indexes:
  - `Repository(id)`, `File(id)`, `File(path)`, `Symbol(name)`, `Chunk(id)`
- Retrieval:
  - Vector search in Postgres → seed nodes; graph expansion via Cypher (k-hop along CONTAINS/REFERENCES/ABOUT).
